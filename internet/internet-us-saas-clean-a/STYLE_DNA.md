# STYLE DNA — 美式SaaS清爽

## Visual signature
**SaaS 命令中心**

## Archetype
`saas-command-center`

## Core motif
左侧产品导航 + 宽 KPI 甲板 + 趋势/活动双区

## Shape language
轻边框、宽卡、长条操作区

## Motion / interaction language
命令面板和详情抽屉

## Recognition gate
The UI must remain recognizable in grayscale and at 20% scale. If it becomes a generic dashboard, it fails this template.
