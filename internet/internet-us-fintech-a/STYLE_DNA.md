# STYLE DNA — 美式金融科技

## Visual signature
**资产账本工作台**

## Archetype
`financial-ledger`

## Core motif
净资产主数字 + 资产分布条 + 交易账本 + 现金流 waterfall

## Shape language
数字对齐、账本行、细趋势线

## Motion / interaction language
范围切换驱动账本和总资产同步

## Recognition gate
The UI must remain recognizable in grayscale and at 20% scale. If it becomes a generic dashboard, it fails this template.
