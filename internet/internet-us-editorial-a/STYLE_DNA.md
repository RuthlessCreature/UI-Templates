# STYLE DNA — 美式编辑部

## Visual signature
**杂志式产品版**

## Archetype
`editorial-spread`

## Core motif
超大标题 + 不对称双栏 + 内容流胜过卡片

## Shape language
粗细字体对比、长分隔线、大留白

## Motion / interaction language
章节/对象切换像翻版面

## Recognition gate
The UI must remain recognizable in grayscale and at 20% scale. If it becomes a generic dashboard, it fails this template.
