# STYLE DNA — 美式高对比扁平

## Visual signature
**美式粗暴块面**

## Archetype
`neo-brutal-blocks`

## Core motif
2px 黑边 + 巨型数字 + 橙红动作砖块

## Shape language
硬边、无阴影、粗标题、矩形按钮

## Motion / interaction language
块面直接替换/推入

## Recognition gate
The UI must remain recognizable in grayscale and at 20% scale. If it becomes a generic dashboard, it fails this template.
