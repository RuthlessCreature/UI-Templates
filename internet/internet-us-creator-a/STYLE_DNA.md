# STYLE DNA — 美式创意工作台

## Visual signature
**无限创作画布**

## Archetype
`infinite-creator-canvas`

## Core motif
左工具轨 + 无限画布 + 右属性岛 + 浮动命令条

## Shape language
画布对象、浮动岛、紫色选择框

## Motion / interaction language
对象自由移动/缩放/吸附

## Recognition gate
The UI must remain recognizable in grayscale and at 20% scale. If it becomes a generic dashboard, it fails this template.
