## Style
更利落、更都市，不用甜腻装饰；莓红只用于选择和关键动作，正文保持中性，适合预约、消费、职业成长和会员服务。

## Design principle
面向目标年龄/性别场景，但不依赖粉色化、幼态化或性别刻板印象；以阅读舒适、信任、效率和品质感为核心。
