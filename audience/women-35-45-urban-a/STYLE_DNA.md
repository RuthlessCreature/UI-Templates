# STYLE DNA — 都市轻熟

## Visual signature
**都市日程服务台**

## Archetype
`urban-agenda`

## Core motif
深色 masthead + 垂直时间轴 + 利落服务卡 + 莓红 CTA

## Shape language
时间线、短卡、窄边、深浅对比

## Motion / interaction language
日程按时间轴滑动

## Recognition gate
The UI must remain recognizable in grayscale and at 20% scale. If it becomes a generic dashboard, it fails this template.
