## Style
品质感来自排版、留白和克制金色，不使用满屏金、黑金会所感或奢侈品仿牌；适合高客单服务、会员、旅行、家居和精品零售。

## Design principle
面向目标年龄/性别场景，但不依赖粉色化、幼态化或性别刻板印象；以阅读舒适、信任、效率和品质感为核心。
