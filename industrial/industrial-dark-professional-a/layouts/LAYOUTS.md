# Layout Recipes — 工业深色专业

## Engineering Workbench
顶部上下文 + 左侧任务树 + 中央工作区 + 右侧属性 + 底部状态。适合检测配置、标定、调参、仿真。

## Operational HMI
状态/配方/连接 → 3–6 KPI → 当前结果/异常 → 主操作。适合运行、报警和班次监控。

## Data / Quality Analysis
范围/时间/筛选 → KPI/趋势 → 主表格/追溯。导出默认继承当前筛选范围。

## Catalog / Navigator
搜索 + 分类 + 紧凑对象卡/列表。按用户意图分组，不按代码模块分组。

## Mobile Companion
状态 → 报警 → KPI → 当前任务 → 主动作。不得把桌面三栏直接缩到手机。

## Style constraint
低眩光深色面板、细边框、克制高亮；适合长期工程调试与控制。
