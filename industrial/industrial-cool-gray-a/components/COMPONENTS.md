# Components — 冷峻灰白

## Core controls
Button / Icon Button / Input / Numeric Input / Select / Checkbox / Radio / Switch / Tabs / Tooltip 均需 default / hover / focus / disabled / error 或对应状态。

## Visual treatment
- Panel：subtle 层次，3px 基准圆角，边框 #C3CCD3。
- Primary Button：#4D7C96；同一操作区原则上一个。
- Data Table：高可扫描；数字右对齐、文本左对齐、状态列固定。
- Status Indicator：颜色 + 图标/文本，不只用红绿。
- Chart：沿用 冷峻灰白 的背景和网格语言，异常线必须明显。
- Alarm：严重级别、来源、时间、原因、处理状态、下一步动作完整。

## Industrial components
Machine/Station Card、Alarm Row、Recipe Card、Device Connection Row、PLC/IO Mapping Row、Image Inspection View、Parameter Group。

## Required states
Loading / Empty / Disconnected / Error / Timeout / Partial Failure / Offline / No Results / Permission Denied。
