# Negative Prompt / Exclusion Rules

Exclude:
- logos, trademarks, company names, customer names, real domains, real accounts
- vendor-specific visual cloning or proprietary wording
- cyberpunk, neon overload, holograms, sci-fi movie interfaces
- game HUD styling, crypto dashboards, consumer social-app styling
- unreadable tiny text, random gibberish, fake dense data with no hierarchy
- decorative gradients used as status encoding
- ambiguous red/green-only state communication
- oversized cards that reduce engineering information density without improving comprehension
