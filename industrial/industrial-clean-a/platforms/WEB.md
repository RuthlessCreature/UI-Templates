# Web Rules

- Preserve the same semantic hierarchy as Desktop, but adapt pane widths responsively.
- At narrower widths, collapse properties into a drawer before collapsing the main task tree.
- Browser refresh/back navigation must not silently lose unsaved engineering changes.
- Long-running actions require persistent progress/state that survives route changes when technically possible.
- Avoid decorative SaaS hero layouts inside operational pages.
- Use URL-addressable views for important objects where appropriate.
