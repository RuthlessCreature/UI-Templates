# PPT Rules

Presentation material inherits the template’s visual grammar without pretending to be interactive software.

Standard slide types:
1. Cover
2. Section divider
3. Executive summary
4. KPI summary
5. System architecture
6. Process / workflow
7. Feature overview
8. Comparison
9. Timeline
10. Case / scenario
11. Risk / issue summary
12. Closing

Rules:
- Use the same neutral palette and spacing logic.
- Keep charts semantically consistent with the product UI.
- Avoid screenshots as the only explanation; annotate purpose and result.
- Base template contains no company logo or customer identity.
