# Desktop Rules

Desktop is the primary platform for this template.

- Optimize for 1366×768 minimum and 1920×1080 reference.
- Keep navigation, workspace, properties, and status areas simultaneously visible when task complexity warrants it.
- Support keyboard focus and shortcuts for repeated engineering operations.
- Use resizable panes for tree/workspace/properties where useful.
- Tables may be dense, but row targets should remain reliably selectable.
- Never hide critical equipment state behind hover.
- Multi-monitor workflows may detach logs/preview panels, but the main window must remain self-sufficient.
