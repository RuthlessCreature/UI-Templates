# Mobile Rules

Mobile is an adapted operational companion, not a compressed desktop.

Priority order: status → alarm → approval/acknowledgement → concise KPI → detail.

- Use one primary task per screen.
- Minimum preferred touch target: 44 px.
- Replace multi-pane layout with drill-down navigation and bottom sheets.
- Avoid large editable engineering parameter matrices on phones unless absolutely required.
- Critical actions must name the affected device/task explicitly.
