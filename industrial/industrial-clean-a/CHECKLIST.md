# UI Review Checklist

## 3-second comprehension
- [ ] 用户知道自己在哪个模块/对象。
- [ ] 当前运行/连接/任务状态清楚。
- [ ] 首屏最重要信息不超过 6 个焦点。
- [ ] 异常有明确等级、来源和入口。
- [ ] 主动作唯一且可预测。

## Information hierarchy
- [ ] L1/L2/L3/L4 权重明显。
- [ ] 元数据不会抢夺主任务注意力。
- [ ] 表格数字右对齐、文本左对齐。
- [ ] 单个数字能回答的问题没有硬画大图。

## Interaction
- [ ] Loading/Empty/Error/Offline 至少已覆盖。
- [ ] 危险操作说明影响对象与范围。
- [ ] 修改参数有合法范围、单位和错误提示。
- [ ] 异步操作有进行中/成功/失败反馈。
- [ ] 关键状态不依赖红绿颜色单独表达。

## Brand neutrality
- [ ] 无公司名、Logo、商标。
- [ ] 无客户名、真实域名、真实账号。
- [ ] 无“模仿某厂商”或 vendor-specific style reference。
- [ ] 模板身份与项目品牌层分离。

## Cross-platform
- [ ] Desktop 不是 PPT 大屏。
- [ ] Web 在常用宽度下可操作。
- [ ] Mobile 重新排序任务而非缩小桌面。
- [ ] PPT 继承视觉语法但不伪装成交互界面。
