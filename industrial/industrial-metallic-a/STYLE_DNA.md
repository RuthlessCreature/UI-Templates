# STYLE DNA — 金属质感

## Visual signature
**金属仪表机架**

## Archetype
`instrument-rack`

## Core motif
垂直仪表条 + 大旋钮/环表 + 机柜分槽

## Shape language
硬边槽位、刻度、表盘、机械分区

## Motion / interaction language
数值/指针变化而非卡片闪动

## Recognition test
This template must remain recognizable in grayscale and at 20% scale. If the screen collapses into a generic sidebar + KPI cards + content panel pattern, it fails this template.

## Do not dilute
- Do not replace the core motif with generic dashboard cards.
- Do not add decorative effects that conflict with the archetype.
- Keep state semantics and accessibility even when the motif is expressive.
