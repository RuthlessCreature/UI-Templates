# STYLE DNA — 国企科技创新

## Visual signature
**科创项目管线**

## Archetype
`innovation-pipeline`

## Core motif
研发阶段 gate + 项目泳道 + 成果里程碑 + 专利/课题卡

## Shape language
泳道、阶段 gate、里程碑菱形

## Motion / interaction language
项目沿阶段管线推进

## Recognition gate
The UI must remain recognizable in grayscale and at 20% scale. If it becomes a generic dashboard, it fails this template.
